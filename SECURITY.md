# Security Policy

This repository is a reproducibility package for research artifacts and
simulation scripts.

## Reporting

Please do not publish credentials, private tokens, private datasets, or
security-sensitive implementation details in public issues.

If you find a security issue in the scripts, dependency setup, or artifact
workflow, use GitHub private vulnerability reporting when available or contact
the repository owner through GitHub.

## Supported scope

The maintained artifact state is the default branch. Historical snapshots are
kept for reproducibility and may not receive separate security updates.
